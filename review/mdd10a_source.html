Description

This MDD10A dual motor driver H-bridge is designed for controlling two brushed DC motors. It supports a wide motor voltage range from 5V to 30VDC (Rev2.0). Please note that there is no reverse polarity protection at Vmotor, so it's essential to double-check the polarity before powering up.

Key Features:

    • Current Handling: Each channel can handle a maximum current of up to 10A continuously and 30A for short bursts (up to 10 seconds).
    • Logic Compatibility: This driver supports 3.3V and 5V logic level inputs for PWM and direction control, making it compatible with popular platforms like Arduino and Raspberry Pi.
    • Solid-State Design: Utilizes solid-state components for faster response times and eliminates the wear and tear associated with mechanical relays.
    • Efficient NMOS H-Bridge: Features a fully NMOS H-bridge design for improved efficiency, eliminating the need for a heat sink.
    • Regenerative Braking: Supports regenerative braking, enhancing motor control capabilities.
    • PWM Control: Offers speed control with a PWM frequency of up to 20KHz (output frequency matches input frequency).
    • PWM Modes: Supports both Locked-Antiphase and Sign-Magnitude PWM operation. Please note that this is not "RC PWM."
    • Activation Buttons: Includes two activation buttons for manual control and fast testing on each channel.
    • Compact Dimensions: Compact size with dimensions of 84.5mm x 62mm.
